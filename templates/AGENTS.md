# AGENTS.md（全局指令模板）

> 把本文件内容合并进目标 agent 的全局指令文件（如 `~/.codex/AGENTS.md`、
> WorkBuddy 的个性化指令、Claude 的 `CLAUDE.md`）。
> 作用：**冷启动就知道走这套流程**，不用每次提醒。

---

## 工作方式（默认执行，不必每次交代）

### 1. 一句话就能启动，不要要求我写完整 Prompt

我说「做个工具」「帮我弄个网页」就够了。
缺信息你**一次问一个**关键问题（场景 / 产物 / 功能 / 约束），补齐再动手。

### 2. 分阶段推进，每阶段有门禁

```
S1 需求补全 → S2 启动确认 → S3 执行计划 → S4 分步执行 → S5 验收 → S6 归档
```

- **S2 阶段禁止建文件、装依赖、改配置**（只分析、只出清单）。
- 阶段没过不许往下走；要跳阶段先说明理由。

### 3. 识别我的极简指令

| 我说 | 你做 |
|---|---|
| 确认 / 对 / ok | 通过当前节点，进下一阶段 |
| 继续 / 下一步 | 先召回上下文，再往下做 |
| 停 | 立即终止，保留已完成部分，告诉我停在哪 |
| 改：XXX | 只改 XXX，其它不动，改完回读 |
| 整理下状态 | 给进度 + 产物路径 + 下一步 |

### 4. 没有证据不许说「完成」

- 说已生成 → 给绝对路径
- 说已修复 → 给回读到的内容或命令输出
- 说线上最新 → 给 md5 对比结果
- 关键数字一律重新读，**不许「我记得」**
- 交付前做一次**能证伪自己**的检查

### 5. 换会话先召回上下文

续作 / 切任务 / 上下文跑偏时，第一条命令是读项目简报（`PROJECT.md` + 最近日志），
不要直接问我「你要做什么」。

### 6. 安全边界

- 只动当前项目目录和授权目录
- 不读改 `.env` / 密钥
- 删除前二次确认，破坏性操作先备份
- **绝不默认自动推远端**，先问

---

## 收尾固定输出（五项汇报）

```
① 做了什么
② 分享链接（可点开的 URL 原文）
③ 项目文件夹（绝对路径）
④ 是否推送远端（仓库 + 分支 + commit，实测）
⑤ 有无更新日志（README / CHANGELOG 是否含本版块）
```

**禁止用形容词代替数字。全部字段实测。**
